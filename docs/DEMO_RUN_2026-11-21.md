## Reproduction and operational limits

Use the [READ / DATA ACCESS launcher guide](LIVE_RECORDING.md) and [WRITE sandbox guide](WRITE_SANDBOX_RECORDING.md). Install the project in a local virtual environment first. The interactive launchers require Windows, an existing current-user CivicGate DPAPI credential, and the named loaded LM Studio model. Never paste secrets into a recording, commit, or chat.

Run benign and review scenarios before repeated authority-violation scenarios if all outcomes must be recorded in one clean session. Do not weaken policy or suppress flags to force a desired outcome. Synthetic mode is explicit, never a fallback for failed live data.

The write executor allows only a fixed note append destination. Before/after equality covers award and notes, not audit files, which grow even for denials. It is not OS isolation and cannot defend against a hostile local process racing filesystem checks. Requests are non-idempotent; if an error occurs after append, inspect state before retrying. The HTTP wait timeout does not cancel an in-flight coroutine; wait for it to finish and inspect state/audit before submitting again. Malformed non-object JSON can return a generic error rather than a validation response. Automated handler-level Origin/Host, body-size and timeout coverage remains follow-up work; these services are local recording aids, not hardened web deployments. Close the launcher with Ctrl+C and verify the listening port is gone; leave unrelated model services alone.

## Publication and validation boundaries

This branch publishes only five demo implementation/UI files, two unit-test files, these guides and this sanitized report, plus README links. Private `audit/` data, videos, credentials and unrelated development code are excluded.

Publication review found a Python 3.11 compatibility issue in the imported sandbox's use of `Path.is_junction` (introduced in Python 3.12). A regression test reproduced the missing-method failure; the sandbox now checks symlink/reparse-point metadata without requiring that method. Junction rejection remains in place on Windows. The demo judge explicitly selects the official repository's `j2-luna` request profile; a mocked transport test asserts the expected completion-token parameter and absence of temperature.
